인벤토리 시스템 — 구조와 시뮬레이터

배달 가방에 물건을 테트리스처럼 채우는 시스템입니다. 먼저 아래 시뮬레이터를 만져 보세요 — 실제 InventoryModel.RecalculateTorque() 계산식을 그대로 옮긴 것이라, 무엇을 어디에 놓느냐가 가방을 어떻게 기울이는지 바로 확인할 수 있습니다. 구조 설명은 그 아래에 있습니다.

1. 토크 시뮬레이터

실제 코드의 InventoryModel.RecalculateTorque() 토크 계산식을 기준으로 만든 간단한 시뮬레이터입니다. 아이템을 선택한 뒤 그리드 셀을 누르면 배치되고, 토크에 따라 인벤토리 판이 기울어집니다.

아이템 팔레트

배치된 아이템을 누르면 선택됩니다. 빈 셀을 누르면 현재 팔레트 아이템 또는 선택된 아이템을 그 위치로 옮깁니다.

현재 값

Torque
0.00

torque = Σ(weight x (itemCenterX - gridCenterX))

Tilt Angle
0.00°

Unity: angle = clamp(-torque x 2, -15, 15)  /  이 페이지(CSS): +torque x 2

해석

토크가 양수면 오른쪽에 무게가 몰린 상태이고, 가방은 오른쪽으로 기웁니다. 실제 코드(InventoryTiltView)는 -torque * degreesPerTorque를 Z축 오일러 각으로 넣고, 이 페이지는 CSS rotate()를 씁니다. Unity의 Z축 양수 회전은 반시계, CSS rotate() 양수는 시계라 부호가 반대여야 같은 방향으로 기울어집니다 — 그래서 여기서는 부호를 뒤집어 적용했습니다. 기우는 방향은 게임과 동일합니다.

2. 구조와 책임

Input

InventoryState 사용자 입력을 집기, 놓기, 회전, 배출 같은 인벤토리 조작 명령으로 변환.
EventSystem UI 선택 상태를 유지해 셀, 아이템, 바깥 보관 영역 간 포커스를 연결.

Controller

InventoryController 입력 명령을 받아 Model을 변경하고 View 갱신을 조율하는 중심 클래스.
드래그 상태 관리 _isDragging, _draggedItem, _pickupOffset, 원래 위치와 바깥 보관함 출처를 보관.

Model

InventoryModel 2D 배열 InventoryItem[,]로 점유 상태, 배치 가능성, 토크 값을 관리.
InventoryItem 아이템 정의, 현재 그리드 위치, 배치 여부, 회전 상태와 실제 크기(EffectiveSize)를 보관.

View

InventoryGridView / ItemView 셀, 아이템 UI, 하이라이트를 표시하고 Model 이벤트에 맞춰 화면을 갱신.
DragPreview / OutsideArea / TiltView 드래그 프리뷰, 보관함 밖 아이템, 토크 기반 기울기 연출을 담당.

3. 집기부터 놓기까지

포인터 좌표 주입 InventoryState.Update()가 매 프레임 SetPointerScreenPosition()을 호출해 현재 조작 위치를 컨트롤러와 동기화한다.
집기 시작 마우스 좌클릭 started 또는 패드 A가 BeginPickupAt(screenPos)를 호출한다. 클릭한 셀에서 아이템을 찾고, 아이템 좌상단과 클릭 셀의 차이를 _pickupOffset에 저장한다.
모델에서 임시 제거 InventoryModel.TryRemove(item)가 그리드 배열을 비우고 item.Unplace() 처리한다. OnItemRemoved 이벤트로 기존 InventoryItemView가 삭제된다.
드래그 프리뷰 표시 InventoryDragPreviewView.Show()가 아이템의 EffectiveSize와 회전 상태에 맞춰 반투명 아이콘을 보여준다.
드래그 중 배치 가능성 표시 UpdateDragging()이 현재 셀에서 _pickupOffset을 뺀 anchor를 계산하고, CanPlace() 결과에 따라 ValidDrop 또는 InvalidDrop 하이라이트를 칠한다. 
Vector2Int? anchorPos = GetDropAnchorPosition(_pointerScreenPosition);
bool canPlace = _model.CanPlace(_draggedItem, anchorPos.Value);

var highlightState = canPlace
    ? CellHighlightState.ValidDrop
    : CellHighlightState.InvalidDrop;
놓기 시도 마우스 좌클릭 canceled 또는 패드 A가 ReleaseAt(screenPos)를 호출한다. anchor가 유효하고 TryPlace()가 성공하면 새 위치에 즉시 배치된다. 
Vector2Int? anchorPos = GetDropAnchorPosition(_pointerScreenPosition);

if (anchorPos.HasValue && _model.TryPlace(_draggedItem, anchorPos.Value))
{
    FinishDrag();
    return;
}

RestoreDraggedItem();
FinishDrag();
성공 또는 복구 성공하면 OnItemPlaced로 새 InventoryItemView가 생성된다. 실패하면 그리드 출신은 원래 셀로, 바깥 영역 출신은 원래 Outside 영역으로 복구된다.

핵심 규칙

배치 좌표는 아이템 좌상단 anchor입니다.

커서가 아이템 내부 어느 칸을 잡았는지 유지하기 위해 cursorCell - _pickupOffset으로 실제 배치 좌상단을 계산합니다.

실패해도 아이템을 잃지 않습니다.

배치할 수 없는 위치에 놓으면 RestoreDraggedItem() 경로로 원래 위치나 원래 보관 영역에 복구됩니다.
