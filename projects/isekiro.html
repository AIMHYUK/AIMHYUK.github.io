패링 / 그래플링 / 타겟 락온

Unreal Engine 5 C++ Blueprint Team 3인
시연 영상
1. 타겟 락온 시스템
  • UActorComponent 기반 모듈형 설계 — 모든 캐릭터에 즉시 탑재 가능
  • 내적(Dot Product)으로 카메라 정면 벡터와 타겟 벡터 유사도 측정, 화면 중앙에 가장 가까운 적 우선 선택
  • RInterp To로 카메라 회전 부드럽게 보간, 락온 상태에서 Strafing 이동 자동 전환
  • Line Trace로 장애물 뒤의 적은 타겟 대상에서 자동 제외
2. 그래플링 훅 시스템
  • 타겟 지점 감지 후 하단 트레이스로 실제 착지 가능 지형(Walkable Surface) 사전 검증
  • Timeline + Curve로 발사 가속 / 도착 감속을 조합한 물리적으로 자연스러운 이동 궤적 구현
  • Cable Component로 발사체와 캐릭터 손 소켓 사이의 물리 연결 및 환경 충돌 구현
  • 애니메이션 노티파이(Anim Notify)로 이동 시작 · 종료 시점과 Flying / Falling 상태 정밀 동기화
3. 패링 시스템
  • USphereComponent 기반 URealParryBox의 Overlap으로 패리 판정 — 일반 약 8프레임, 위험(Hazard) 상태 1프레임으로 난이도 연동
  • 패리 입력 시 데미지 채널 충돌 응답을 즉시 Ignore로 전환하여 무적 판정 구현, 패리 종료 시 복구
  • 패리 성공 시 SetGlobalTimeDilation(0.85f)로 슬로우 모션 적용 후 0.5초 뒤 타이머로 복구
  • 패리 성공마다 보스 자세 데미지(3) 누적, 자세 붕괴 시 처형 연출 트리거
  • 패리 윈도우와 쿨다운을 별도 FTimerHandle로 분리 — 연속 패리 어뷰징 방지
  • 구현 — URealParryBox::ParryStarted에서 짧은 패리 윈도우를 열고, FTimerHandle로 판정 종료와 쿨다운을 분리했습니다. 성공 시 OnParryCheckBeginOverlap에서 패리 몽타주, 충돌 이펙트, 보스 자세 데미지, 히트스톱을 처리했습니다.
// 실제 구현 요약 - 입력 순간 패리 윈도우를 열고 타이머로 닫는 구조
void URealParryBox::ParryStarted()
{
    if (!bCanParry) return;

    bIsParryWindow = true;
    SetCollisionEnabled(ECollisionEnabled::QueryAndPhysics);
    MyCharacter->GetCapsuleComponent()->SetCollisionResponseToChannel(
        ECC_GameTraceChannel3, ECR_Ignore);

    const float WindowFrame =
        MyCharacter->GetHazardState() == EHazardState::EHS_Hazard ? 1.f : 8.f;
    GetWorld()->GetTimerManager().SetTimer(
        ParryTimerHandle, this, &URealParryBox::ParryEnded, WindowFrame / 60.f, false);
}
  • 문제 — 프로토타입 단계라 패리 박스가 캐릭터, 보스, 슬로우 모션, 자세 데미지를 모두 알고 있어 책임이 큽니다. 또한 보스 참조와 전역 TimeDilation 사용은 확장 시 부작용이 생길 수 있습니다.
  • 개선 방향 — 패리 박스는 “패리 성공 이벤트 발생”까지만 담당하게 줄이고, 자세 데미지·히트스톱·처형 가능 여부는 전투 컴포넌트나 이벤트 구독 쪽으로 분리하겠습니다. 판정 시간도 프레임 상수보다 데이터 에셋/애니메이션 노티파이 기반으로 옮기겠습니다.
